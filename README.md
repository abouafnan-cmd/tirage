# 📖 منصة تعلم الإنجليزية من سورة البقرة

تطبيق ويب تقدمي (PWA) مفتوح المصدر يهدف إلى تعليم اللغة الإنجليزية من خلال ترجمة معاني سورة البقرة (ترجمة تقي الدين الهلالي ومحسن خان). يدمج التطبيق بين الجانب الروحي التأملي والتعلم اللغوي العميق من خلال تقديم إضاءات نحوية، مفردات منتقاة، وميزة النطق الصوتي لكل آية.

## ✨ مميزات المنصة
- **البحث السريع:** استعراض الآيات بسهولة عبر إدخال رقم الآية (1 - 286).
- **العرض المزدوج:** عرض النص القرآني باللغة العربية مع الترجمة الإنجليزية المعتمدة.
- **الإضاءات اللغوية التربوية:** استخراج أهم المفردات وشرح القواعد النحوية المرتبطة بسياق الآية لتسهيل بناء المناهج التعليمية.
- **القراءة الصوتية:** نطق آلي للترجمة الإنجليزية باستخدام واجهة (Web Speech API) لتحسين مهارات الاستماع.
- **العمل دون اتصال (Offline-first):** بفضل تقنية PWA، يمكن للمستخدمين الوصول إلى المحتوى حتى عند انقطاع الإنترنت.
- **متعدد المنصات:** يعمل كموقع ويب سريع الاستجابة، ويمكن تحزيمه كتطبيق أندرويد متكامل.

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** HTML5, CSS3 
- **المنطق البرمجي (Logic):** Vanilla JavaScript (ES6+)
- **قاعدة البيانات:** هيكل `JSON` مبسط وسريع الاستدعاء.
- **ميزات الويب التقدمي:** Service Worker & Web App Manifest.
